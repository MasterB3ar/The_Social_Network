# TSN V1.4.2 — Notification + Reaction Visual Rewrite

This update is a stronger UI rewrite for the two parts that still looked bad in V1.4.1.

## Changed

- Rebuilt the notifications view into a cleaner inbox-style panel.
- Added an unread summary card at the top of notifications.
- Notifications now have cleaner spacing, unread dots, better icons, and better mobile layout.
- Removed the always-visible `...` reaction/menu dot from messages.
- Messages still open the action/reaction popup when clicked or tapped.
- Reaction counts now show only when a message actually has reactions.
- Rebuilt the popup reaction menu into a cleaner action sheet.
- Reaction buttons are larger, rounder, and easier to tap on mobile.
- Report/delete actions moved into a cleaner footer inside the popup.

## Notes

- No new environment variables are required.
- TSNM is still removed.
- Admin private-message privacy rules are unchanged.
