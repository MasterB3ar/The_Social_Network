# TSN V1.5.21 — Private Chat UI Refresh

This update refreshes the private chat UI and media display.

## Changes

- Private chat panel is wider and cleaner on desktop.
- Private chat becomes a full-screen chat view on mobile.
- Private chat header, messages, input bar, and media picker have been restyled.
- Private image/GIF messages are larger and cleaner.
- Image messages use `object-fit: contain` in chat so media is not cropped badly.
- Private media picker has more room and a clearer scroll area.
- Search controls stay separated from the image grid.

No new environment variables are required.
