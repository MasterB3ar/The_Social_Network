# TSN V1.5.11 — Verified AI Admin Visibility

Admins can now read private messages sent by users who have the custom badge `Verified AI`.

Scope:

- Admins can still read global chat moderation archive.
- Admins can now see private messages where the sender has the exact custom badge `Verified AI`.
- Other private messages remain hidden from admin browsing; only counts are shown.
- Reported private-message evidence is still visible as before.
- The admin message filter now includes `Verified AI private beskeder`.

Badge matching is case-insensitive, but the intended badge label is `Verified AI`.
