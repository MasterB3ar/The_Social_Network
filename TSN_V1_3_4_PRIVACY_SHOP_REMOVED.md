# TSN V1.3.4 update

## Removed from normal TSN

- Shop page
- Balance display
- Purchasable profile pictures
- Animated avatar purchases
- Buyable chat pictures
- Chat-picture sending
- TSN-S wallet sharing variables

## Admin private-message privacy

Admins cannot read private message bodies anymore.

They can still see counts, including total private messages and per-user private message totals.
