# TSN V1.5.10 — Bigger Pictures

This update makes pictures and GIFs much larger in TSN.

## Changed

- Global chat pictures/GIFs are larger.
- Private chat pictures/GIFs are larger.
- Message popup image preview is larger.
- Media picker thumbnails are much larger.
- Mobile layout uses one large media card per row.
- Desktop layout uses larger grid cards.

## Environment variables

No new environment variables were added.
