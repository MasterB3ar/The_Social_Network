# TSN V2.0 — Spam Alert Removed

Version remains `2.0.0`.

## Changed

- Disabled automatic server-side anti-spam blocking.
- Users can now send fast/repeated global chat messages without the spam alert stopping them.
- Users can now send fast/repeated private messages without the spam alert stopping them.
- Global post comments are no longer blocked by the spam alert.
- Render and `.env` examples now use `TSN_ANTI_SPAM_ENABLED=false`.
- Rules text was updated so it no longer says automatic spam can mute users.

## Still unchanged

- Manual admin moderation tools still exist.
- Manual mute/ban/delete still exists.
- Content filter settings are unchanged.
- Package version remains `2.0.0`.
