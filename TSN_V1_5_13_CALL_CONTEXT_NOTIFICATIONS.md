# TSN V1.5.13 — Call + Context Notifications Update

This update adds call ringtone/timeout behaviour and replaces the old notification tab with contextual notification badges.

## Changes

- Incoming calls play a ringtone.
- Calls auto-end after 10 seconds if unanswered.
- Calls use a floating overlay so TSN remains usable during the call.
- Notification tab removed from the sidebar.
- Private message unread count appears on the Private Chat nav button.
- Global @mentions appear on the Global Chat nav button and as a bottom banner.

No new environment variables are required.
