# TSN V1.4.1 — Reaction Popup + Notification Polish

## Changed

- The Notifications page has a cleaner inbox-style design.
- Global chat messages are clickable/tappable and open a message popup.
- Private messages are clickable/tappable and open a message popup.
- Emoji reactions are now inside the popup instead of always visible under every message.
- Existing reaction counts still show on messages as small compact chips.
- Report/delete actions were moved into the same message popup.
- Mobile styling was improved for the popup and notifications.

## Not changed

- TSNM is still removed from normal TSN.
- Admins still cannot browse all private messages.
- Reported private-message evidence remains visible to admins when reviewing reports.
- No new environment variables are needed.
