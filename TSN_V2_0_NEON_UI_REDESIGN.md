# TSN V2.0 — Neon UI Redesign + Mobile Polish

Bygger videre på TSN V1.5.36. Målet er at gøre TSN markant sejere visuelt uden at ødelægge det fungerende global-chat-layout.

## Ændringer

- Nyt V2.0 neon/glass tema.
- Ny auth hero og V2 branding.
- Topbar redesignet som command bar med live-chip.
- Sidebar/app navigation redesignet.
- Global chat beholder klassisk opsætning, men med ny V2 styling.
- Private chat, brugerlisten, profilkort, adminpaneler, events og modals får V2 polish.
- Opkalds-UI og bundbjælke poleret visuelt.
- Mobilvenlige overrides til små skærme.
- Version opdateret til 2.0.0.
