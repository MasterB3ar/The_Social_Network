# TSN V1.5.19 — Better Media Send Layout

This update improves the visual layout for sending GIFs/photos in TSN.

## Changed

- Cleaner media picker layout.
- Better GIPHY/Pixabay search header.
- Larger result cards.
- Clearer selected-media state.
- Selected media preview card inside the picker.
- Improved selected media preview above the message input.
- Better mobile layout.
- Still blocks random uploads/custom URLs/base64.

No new environment variables are required.
