# TSN V1.5.25 — Media Picker Fluid Header

- The “Find GIFs/fotos” header now follows the scroll movement instead of only snapping hidden/visible.
- Scrolling down pushes the header up in sync with the scroll distance/speed.
- Scrolling up brings the header back down in sync with the scroll movement.
- Works in Global Chat and Private Chat.
- No new environment variables.
